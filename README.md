## 📚 Sobre
Este repositório contém anotações, scripts, arquivos de configuração e projetos práticos desenvolvidos durante a minha formação na trilha "Começando em **DevOps**" pela Alura. O objetivo é documentar minha evolução em infraestrutura como código (IaC), automação, monitoramento e arquitetura em nuvem.

## 🗂️ Estrutura do Repositório
O conteúdo está organizado pelas tecnologias e cursos abordados na trilha:

- **`/aws-elastic-beanstalk`**: Deploy de aplicações, orquestração de containers na nuvem, Load Balancers e Auto Scaling.
- **`/docker`**: Dockerfiles, docker-compose, criação e otimização de imagens.
- **`/linux`**: Comandos essenciais, gerenciamento de processos, scripts Shell e permissões.
- **`/ci-cd`**: Pipelines de integração e entrega contínua.
- **`/git`**: Fluxos de trabalho e versionamento.

## 🛠️ Tecnologias e Ferramentas
* **Cloud Provider:** Amazon Web Services (AWS - EC2, Elastic Beanstalk, CloudWatch, S3)
* **Containerização:** Docker & Docker Compose
* **OS:** Linux (Ubuntu/Amazon Linux 2023)
* **Versionamento:** Git & GitHub
* **Scripting:** Bash/Shell Script

## 📝 Aprendizados Chave
- [x] Provisionamento de infraestrutura escalável na AWS usando Elastic Beanstalk.
